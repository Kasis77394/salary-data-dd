# Salary Prediction with Linear Regression

A beginner project that predicts salary from years of experience using
NumPy, Pandas and Matplotlib (no scikit-learn).

**Dataset:** Salary Data from Kaggle (30 rows: YearsExperience, Salary).

**What I did:**
- Loaded and explored the data with Pandas
- Checked for missing values (found none)
- Plotted experience vs salary (the dots rise in a straight band)
- Built linear regression from scratch with the normal equation
- Plotted the best-fit line and predicted salary

**What I learned:** I learned how to explore and check data (like looking
for missing values) and understood the linear regression steps more clearly.

**Still learning:** Why the normal equation gives the best fit
(I haven't reached projections in linear algebra yet).
